# truck adapter notes (truck-modeling 0.6.0, shapeops 0.4.0, stepio 0.3.0, meshalgo 0.4.0)

Signatures verified in `~/.cargo/registry/src/*/truck-*`:

- `builder::vertex(Point3) -> Vertex`; `line(&v0,&v1)`; `circle_arc(&v0,&v1,transit) -> Edge`.
- `builder::tsweep(&elem, Vector3)` (vertex→edge→face→solid). `rsweep(&elem, origin, axis, Rad)`: |angle| ≥ 2π is a closed sweep.
- `builder::cone(&Wire, axis, Rad) -> Shell` (revolve whose end points on the axis are collapsed); `Solid::try_new(vec![shell])`.
- `builder::try_attach_plane(&[Wire]) -> Result<Face>`; `try_wire_homotopy(&Wire,&Wire) -> Result<Shell>` (ruled loft, same edge count).
- `truck_shapeops::{and, or}(&Solid,&Solid,tol) -> Option<Solid>`; difference = `and(a, &b.not())`. `unwrap`s on empty solids; kernel panics in `Solid::new` seen (3a).
- Mesh: `MeshableShape::triangulation(tol).to_polygon()` + `put_together_same_attrs(tol)`; `RobustMeshableShape::robust_triangulation` for STEP-imported shells. Volume/area only from the mesh.
- STEP out: `CompleteStepDisplay::new(StepModel::from(&solid.compress()), StepHeaderDescriptor{..})` (fill all fields: `Default` reads chrono clock). STEP in: `Table::from_step(&str)` → `table.shell` → `to_compressed_shell` → `robust_triangulation`.
- Not available: fillet, chamfer, shell, face offset/move, sweep along a curve → `not_exposed`.

## Findings (final run; timings indicative, other backends were running)
- `Solid::is_geometric_consistent` is unusable: `unimplemented!` panic (truck-modeling geometry.rs:228/234) on any `IntersectionCurve` edge (= every boolean result) and infinite recursion / stack overflow on a `RevolutedCurve` generated by a `Line` (cone). Adapter skips it in those cases (`backend_valid = None`, noted).
- `put_together_same_attrs` (kernel mesh weld) stack-overflows on the cone mesh (11b); skipped there. Without the weld, per-face meshes are not watertight.
- 1a/1b: work, volume rel. err 1e-5 / 5e-6; mesh still has a few open/non-manifold edges (b6 nm1 / b9) after weld; 13c (mesh of 1a at 0.01) is watertight.
- 2a/2b: `or` returns `None` (coplanar shared face / shared edge not handled). 3a (tangent cylinder): kernel panic "This shell is not oriented and closed." in `Solid::new` inside the boolean. 3b (tangent sphere): works but mesh has 6 non-manifold edges (pole degeneracies).
- 4 (plate + 100 pins folded with `or`): >45 s timeout.
- 10b/10c: ok and watertight; 11a/11b/13a/13b: volumes ok (2e-4 / 5e-5), meshes have degenerate pole triangles (nm6 mo12); sphere chord deviation 0.043 (tol 0.01) and 0.37 (tol 0.1) — tolerance is not honoured on spheres.
- 5a–9b, 10a: not exposed (no fillet/chamfer/shell/offset/curve sweep). History: none.
- STEP write works for all built solids. Round-trip (12rt): 10b/10c ok (2e-10); 11a/11b re-import with negative volume (3.0 rel. err, orientation/pole problem in the reader's surface of revolution); 1b re-imports with 78% error; 1a hangs (stderr "Lookup failed for #573", reader loops); 4 times out.
- Hostile `BoxMinusCylinder`: NaN input hangs (>45 s). Fillet/PushPull families N/E.
- wasm32: compiles, 1.50 MB raw / 347 KB gzip; in node 3/18 ok, 11 N/E, 2 error (2a, 2b), 1 trap (3a, `unreachable`), 1 timeout (4) — identical to native. `getrandom` needs the `js` feature.
